# Roomie project documents

This folder contains the initial product and engineering specification
for Roomie.

-   `PRD.md` --- product requirements and MVP scope.
-   `USER_FLOWS.md` --- student, listing, matching, messaging and admin
    journeys.
-   `DATABASE_SCHEMA.md` --- PostgreSQL entities, relationships,
    constraints and indexes.
-   `IMPLEMENTATION_ROADMAP.md` --- stack, repository structure, phases,
    testing and deployment.

These documents represent version 1.0 of the baseline specification
dated 11 November 2026. Update them as product decisions change.
